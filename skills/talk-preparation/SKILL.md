# 登壇準備

社外イベントでの登壇を、段階ごとに 1 つのページを作りながら準備する。資料を作り始める前に、イベントが求めているものと、自分が足せるものを決めることに重きを置く。

## いつ使うか

- 社外イベントでの登壇が決まったとき（依頼を受けた、CFP が採択された）
- 登壇のテーマを決めたいとき
- 登壇資料や想定問答を作る前に、材料を集めて整理したいとき

## 段階と成果物

段階ごとに 1 ページを作る。ページの雛形は [reference/template.md](reference/template.md) にある。

| 段階 | 成果物 | 決めること |
| --- | --- | --- |
| 1. イベントの把握 | イベント概要 | 持ち時間、質疑の形、聴き手、主催との取り決め |
| 2. テーマ決め | テーマ | 全体を通す線、既存の発信に足すもの、話す深さ |
| 3. 情報収集 | 情報収集 | 話す材料、エピソードの候補、非公開情報 |
| 4. アウトライン | アウトライン | 構成と時間配分 |
| 5. 資料作成 | 資料 | |
| 6. 想定問答 | 想定問答 | 答え方と、答えないこと |
| 7. 発信の後追い | 記事など | 書くかどうか |

親ページに、段階・期限・状態の表と、各ページへのリンクを置く。

## 1. イベントの把握

やること:

1. 日程、会場、形式、持ち時間、質疑の受け方を書く。途中で変わったら、変わった点を分けて書く
2. 依頼を受けた場合は、依頼の理由（なぜ自分に声がかかったか）を写す。既存の記事や発表がきっかけなら、それがテーマの起点になる
3. 主催が想定する聴き手と、それぞれに持ち帰ってほしいものを表にする
4. 他の登壇者がいるなら、その人たちの直近の発表を調べる。同じ題材が並ぶかどうかを把握する
5. 主催との取り決めを書く。資料の公開、録画や配信、イベントレポートの有無と事前確認の有無

## 2. テーマ決め

やること:

1. イベントのテーマと依頼の理由から、キーワードを抜き出す。キーワードごとに、意味と出どころを書く
2. 既存の発信がきっかけなら、「既存の発信の節 × 対応するキーワード × 足すもの」の表を作る。足すものが無い節は、話す価値が薄い
3. 全体を通す線を 1 本決める。各節がその線のどこに当たるかを言えるようにする
4. 話す深さを決める。技術の詳細まで話すのか、判断の理由までにとどめるのか
5. 決めきれないことは「未決」として残し、アウトラインに入る前に片付ける

守ること:

- 既存の記事や発表の再演にしない。聴き手の一部はすでに読んでいる
- イベントが「意思決定」や「苦労」を主題にしているなら、成功談だけで構成しない。判断を変えたこと、揺れたこと、進め方を切り替えたことを候補にする
- 他の登壇者と題材が重なるなら、切り口（技術か組織か、立ち上げか運用か）で差を付ける

## 3. 情報収集

やること:

1. 出典の表を作る。資料名と場所（URL やローカルのパス）を並べる
2. 時系列の表を作る。時期を確かめられなかった出来事は「時期は未確認」と書き、推測で埋めない
3. テーマのキーワードごとに材料を並べる。主張を太字で書き、根拠を続ける
4. 既存の発信がきっかけなら、そこに書かれていないことを抜き出す。テーマ決めの「足すもの」の材料になる
5. エピソードの候補を表にする。判断を変えたこと、うまくいかなかったこと、苦労したことなどを、中身と出典とともに書く。どれを話すかはアウトラインで決める
6. 非公開情報を表にする。判断の順序と観点は [reference/disclosure.md](reference/disclosure.md) にある
7. 数字や時期は、資料に書く前に一次ソースで確かめる。手順は `fact-verification` を使う

守ること:

- 材料を集める段階で、話す内容を決めない。決めるのはテーマとアウトライン

## 4. アウトライン

やること:

1. 持ち時間から、節ごとの時間を割り振る
2. 見出しだけを読んで、全体の流れと持ち帰ってほしいことが分かるかを確かめる。文章の観点は `technical-writing` を使う
3. 各節が、テーマで決めた「全体を通す線」と「足すもの」のどちらに当たるかを書く

## 5. 資料作成

やること:

1. アウトラインの節の順に作る
2. 非公開情報は、確認が済むまで資料に入れない。入れた場合は、どこに入れたかを控えておく

## 6. 想定問答

やること:

1. 質疑の形（セッション直後か、パネルでまとめてか、事前に集めるか）を確かめる
2. 聴き手ごとに、聞かれそうな質問を挙げる
3. 他の登壇者がいるなら、比べる質問（なぜその選択をしたか、違いは何か）を用意する
4. 非公開情報を聞かれたときの答え方を決めておく

## 7. 発信の後追い

やること:

1. 登壇の内容を記事にするかを決める。時間の都合で削った話や、資料だけでは伝わらない判断の理由があれば候補になる
2. 主催がイベントレポートを公開するなら、事前確認で非公開情報が含まれていないかを見る
