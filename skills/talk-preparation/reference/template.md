# 登壇準備のページ雛形

1 回の登壇につき 1 つのフォルダ（または親ページ）を作り、段階ごとのページを並べる。

```
<イベント名>/
├── <イベント名>.md   親ページ
├── イベント概要.md
├── テーマ.md
├── 情報収集.md
├── アウトライン.md
└── 想定問答.md
```

## 親ページ

```markdown
# <イベント名>

## 目的

<この登壇で何を達成したいか>

## タスク

| タスク | 期限 | 状態 |
| :--- | :--- | :--- |
| イベントの把握 | | |
| テーマ決め | | |
| 情報収集 | | |
| アウトライン作成 | | |
| 資料作成 | | |
| 想定問答 | | |
| 発信の後追い | | |

## ページ

- [イベント概要](イベント概要.md)
- [テーマ](テーマ.md)
- [情報収集](情報収集.md)
- [アウトライン](アウトライン.md)
- [想定問答](想定問答.md)
```
