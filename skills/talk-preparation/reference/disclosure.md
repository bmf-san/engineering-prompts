# 社外に出す前に確認する情報

社内の資料から登壇の材料を集めると、社外に出せない情報が混ざる。情報収集の段階で表に挙げ、資料に入れる前に確認する。

## 観点

| 種類 | 例 | 確認すること |
| :--- | :--- | :--- |
| 事業の数値 | 売上や ARR の目標、特定機能の売上、市場規模の社内試算 | 社外で公表している数字か |
| 障害・インシデント | 過去の障害の日付、影響範囲、原因 | 社外に公表しているか。公表済みなら、公表した範囲を超えていないか |
| 社内の開発データ | 変更者数、PR の件数や比率、レビュー率 | 社外に出してよいか。出すなら、丸めた値や傾向で足りないか |
| システム構成の細部 | 内部のエンドポイント、ネットワーク構成、移行中の依存関係、既知の弱点 | 攻撃の手がかりにならないか |
| 社内の意思決定の経緯 | 却下した案、関係者間の意見の対立 | 関係者が社外で話されることに同意しているか |
| 他社・共催先から得た情報 | 打ち合わせで聞いた他社の構成や事情 | 先方が公表しているか。NDA がなくても、先方の確認なしに出さない |
| 個人に紐づく情報 | 関係者の名前、評価、発言 | 本人の同意があるか |

## 守ること

- 確認が済むまで、資料に入れない
- 確認先（広報、セキュリティの担当、上長、関係者本人）と、確認の結果をページに残す
- 想定問答に「答えないこと」として載せ、聞かれたときの答え方を決めておく
