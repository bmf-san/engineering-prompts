# 批判的思考

主張を、受け入れる前に吟味する。疑うこと自体が目的ではない。どこまで信じてよいかを決め、その確信度に見合った判断をする。

## いつ使うか

- 提案・設計・技術選定の根拠が「他社がやっている」「〇〇で効果があった」のときに、自分たちにも当てはまるかを見極めるとき
- ベンチマーク、アンケート、ポストモーテム、障害の原因分析など、データから結論を出している主張を受け取ったとき
- 自分の判断に確信があり、反対意見を聞く前に決めてしまいそうなとき
- 議論で強い言い方や権威のある人の意見に、話が引っ張られているとき

自分の主張を組み立てるところは `logical-thinking`、根拠を一次ソースに当たり直して確かめるところは `fact-verification`、何を解くべきかを決めるところは `problem-framing` を使う。

## 1. 主張を取り出す

やること:

1. 吟味する主張を一文で書く。話し手の言い方ではなく、何が言われているかを書く
2. 主張の種類を分ける。事実（何が起きたか）、因果（何が何を起こしたか）、予測（何が起きるか）、価値（何が望ましいか）で、確かめ方が変わる
3. 主張が何の判断に使われるかを書く。判断に影響しない主張は、深く吟味しない

守ること:

- 話し手の立場や印象で、主張を評価しない。主張と話し手を分ける
- 曖昧な言葉（「遅い」「よく使われている」「安全」）は、何と比べてどうなのかを書き直してから吟味する

## 2. 証拠の強さを見る

やること:

1. 主張を支えている証拠を書き出す
2. 証拠の種類で強さを見積もる。経験談、一つの事例、他社の発表は弱い。比較のある測定、複数の独立した事例は強い
3. 証拠がどう集められたかを見る。都合のよい事例だけが残っていないか（成功した事例だけが語られている、失敗した事例が表に出ていない）、測定の条件が本番と違わないか
4. 主張する人の動機を見る。売り込み、自分の成果、引くに引けない事情があるときは、証拠を一段弱く見る

守ること:

- 権威・多数派・他社の採用を、それだけで証拠として扱わない。「なぜその人たちはそう判断したか」まで下りる
- 証拠の数で納得しない。同じ元の情報から出た証拠は、何件あっても一件として数える

## 3. 別の説明を探す

やること:

1. 同じ証拠を説明できる、別の原因・解釈を少なくとも二つ書く
2. 因果の主張なら、次を確かめる
   - 逆向きではないか（結果が原因を生んでいないか）
   - 両方を起こしている第三の要因はないか（同じ時期のリリース、季節性、トラフィックの変化）
   - 偶然や平均への回帰で説明できないか（一番悪かった時期に打ち手を入れて、元に戻っただけではないか）
3. 別の説明と元の主張とで、どの証拠があれば区別できるかを書く。区別できる証拠を取れるなら取りにいく

守ること:

- 最初に浮かんだ説明で止めない。最初の説明は、手元の情報で一番話をつくりやすいものにすぎない
- 別の説明を否定できないうちは、元の主張を確定した事実として扱わない

## 4. 一般化の範囲を確かめる

やること:

1. 証拠が得られた条件（規模、負荷、チームの体制、ドメイン、時期）を書く
2. 自分たちの条件と並べ、違うところが結論に効くかを判断する
3. 効く違いがあれば、主張を「その条件では」と範囲を絞って受け取る

守ること:

- 他社事例やベンチマークを、条件を確かめずに自分たちの見積もりに使わない
- 「うまくいった」という報告は、何と比べてうまくいったのかが分かるまで受け取らない

## 5. 自分の思い込みを点検する

他人の主張より、自分の判断のほうが吟味が甘くなる。次の問いを自分に向ける。

| 思い込み | 自分への問い |
| :--- | :--- |
| 確証バイアス | 自分の考えに合う情報ばかり集めていないか。反対の証拠を探したか |
| 最初の数字への引きずられ | 最初に出た見積もりや案を基準に考えていないか。白紙から出したら同じ値になるか |
| 引くに引けない | これまでの投資を理由に続けていないか。今から始めるとしても同じ判断をするか |
| 手に入りやすい情報 | 最近の障害や目立った事例を、頻度の高いことと取り違えていないか |
| 後知恵 | 結果を知っているから、当時の判断を誤りと見ていないか。当時手に入った情報で判断を評価したか |
| 自分の案への愛着 | 他人が同じ案を出したら、同じ強さで支持するか |

やること:

1. 自分の結論に反対する立場で、一番強い反論を書く。反論に答えられないなら、結論を保留する
2. 判断に関わる人に、反論を出してもらう。反論が出ない場を、同意の証拠として扱わない

## 6. 確信度を決める

やること:

1. 吟味した結果を、確信度で表す（確か、たぶん、分からない、たぶん違う）
2. 考えを変える条件を書く。「〇〇が観測されたら、この判断を見直す」
3. 確信度に合わせて判断の仕方を変える。確信度が低く、取り返しのつかない判断なら、小さく試す・後で戻せる形にする・判断を先送りする

守ること:

- 確信度が低いことを理由に、判断を止めない。分からないまま決める必要があるなら、分からないことを書いて決める
- 吟味の深さを、判断の重さに合わせる。戻せる小さな判断に、重い吟味をかけない

## 7. 点検

吟味を終えたら、次の型に当てはまるところがないかを見る。

| 型 | 見分け方 | 直し方 |
| :--- | :--- | :--- |
| 鵜呑み | 証拠の集め方や条件を見ずに、結論だけを受け取っている | 2 と 4 に戻り、証拠の種類と条件を書き出す |
| 疑いっぱなし | 反論は並んでいるが、どこまで信じるかが決まっていない | 確信度と、考えを変える条件を書く |
| 一つの説明で決め打ち | 別の説明を検討した跡がない | 別の説明を二つ書き、区別できる証拠を挙げる |
| 権威への寄りかかり | 「〇〇さんが言っていた」「大手が採用している」が根拠の中心になっている | その判断の理由まで下り、自分たちの条件で成り立つかを見る |
| 条件の取り違え | 違う規模・負荷・体制で得られた結果を、そのまま当てはめている | 条件を並べ、効く違いがあれば範囲を絞る |
| 相手によって基準が変わる | 自分の案と他人の案で、求める証拠の強さが違う | 同じ問いを両方に向ける |
