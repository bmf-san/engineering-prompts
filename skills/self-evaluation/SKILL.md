# 自己評価

自分の目標の実績を集め、期初の達成基準に照らして評価を付け、評価者が確かめられる形で書く。

## いつ使うか

- 中間・期末の自己評価を書くとき
- 評価シートに書く前に、下書きで実績を整理したいとき

評価者としてメンバーを評価するときは `member-evaluation`、昇格の推薦は `promotion-assessment` を使う。

## 入力

- 評価制度のガイド。評価の段階、点数、目標の区分と重み、総合の出し方
- 期初の目標と達成基準。評価シートの写しではなく、元の目標のページ
- 活動の記録。日々の記録、PR、文書、チャットの発言
- 等級要件とスキルマップ。あれば使う
- 組織の下書きフォーマット。あればそれに従い、この skill の手順は中身の書き方に使う

## 1. 準備する

やること:

1. 評価制度のガイドと目標設定のガイドの最新版を読む
2. 期初の目標と達成基準を、元の目標のページから写す
3. 評価の対象期間を確かめる。中間なら前半、期末なら後半の成果と行動を材料にする
4. 活動の記録がそろっているかを確かめる。抜けがあれば、書き始める前に埋める

守ること:

- 評価シートの写しを達成基準として使わない。指標の一部しか写していないことがある
- 定義が空欄の水準があれば、どう扱うかを決めてから書く。必要なら上長とそろえる

## 2. 実績を集める

やること:

1. 目標ごとに、関わった活動を記録から拾う
2. 拾った活動の成果物（PR、文書、記録）を一つずつ開いて確かめる
3. 自分の成果かを確かめる。レビューしただけのものや、他の人が書いたものは数えない
4. 目標の外の貢献は、目標ごとの実績と分けて集める

守ること:

- 記憶で書かない。開いて確かめられないものは書かない
- 根拠に挙げる資料は、実際に使われたかを確かめる。叩きや構想の段階で止まっているものは根拠にしない
- 対象期間の外の活動は混ぜない。次の評価に回す

## 3. 書く

やること:

1. 目標ごとに「何をしたか」「何にどう効いたか」「根拠」を分けて書く
2. 「何にどう効いたか」は、目標と達成基準へのつながりで書く
3. 達成基準の水準ごとに、達成か未達かと、その理由を書く。そのうえで評価を一つ選ぶ
4. 総合は、評価制度のガイドの出し方で出す。点数の加重平均で決める制度なら、基準点以上となる評価にする
5. 行動評価は、各項目の行動例に対応する事例を選ぶ

守ること:

- 事実だけを書く。推測や意図を書くときは、それと分かる書き方にする
- 数値は、対象・期間・母数を本文に書く。似た数値が複数あるときは、範囲の違いを書く
- 因果を言い過ぎない。時系列で書く（例: 見直した後は〜に縮んだ）
- 集計の切り方で大きく揺れる指標は使わない。揺れにくい定義で取り直す
- 「〜に沿って判断した」と書くときは、その文書が判断より前にあったかを確かめる
- 1on1 の内容と、他の人の自己評価は根拠にしない
- 総合を「最も近い評価」にしない
- 行動評価の事例は、目標の実績と重ねない

## 4. 提出前に確かめる

やること:

1. すべての目標を、期初の達成基準に照らしているか
2. 目標の区分と重みが、目標の記録と評価制度のガイドで食い違っていないか
3. 上長とそろえるべきものをそろえたか。チーム全員が同じ評価になる目標や、中間で見直した指標
4. 下書きと参照した資料を、期ごとに残す

守ること:

- 評価シートの保存と確定の操作を確かめる。確定した後は変更できない仕組みもある
- 下書きと資料は、自分と評価者だけが見る場所に置く
