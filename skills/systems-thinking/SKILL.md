# システム思考

原因と結果が循環している問題を、出来事ではなく構造として捉える。一つの原因を取り除くのではなく、ループのどこに手を入れると全体が変わるかを選ぶ。

## いつ使うか

- 手を打っても、しばらくすると同じ問題が戻ってくるとき
- 原因を一つに絞れず、「あれもこれも関係している」状態のとき
- ある打ち手が、別のところに問題を生んだとき
- チームや組織をまたぐ問題で、それぞれの部分は正しく動いているのに全体がうまくいかないとき

原因から結果へ一方向にたどれる問題は `problem-framing`、主張と根拠のつながりは `logical-thinking`、要素の分け方は `structuring` を使う。

## 1. 時系列で見る

やること:

1. 問題を出来事としてではなく、時間の中での変化として書く。何が、いつから、どう変わってきたか
2. 変化のパターンを見分ける
   - 増え続ける・減り続ける
   - 頭打ちになる
   - 振れる（増えては減る）
   - 打ち手のあとで一度良くなり、また悪くなる
3. 数字があれば、グラフにして形を見る。なければ、関係者に「以前はどうだったか」を聞いて形を描く

守ること:

- 一つの出来事から構造を決めない。同じ形が繰り返されているかを先に確かめる

## 2. 要素とつながりを書く

やること:

1. 溜まっていくもの（ストック）を書き出す。例: 未対応の問い合わせ、技術的負債、メンバーの知識、信頼
2. それぞれのストックを増やす流れと減らす流れを書く
3. 流れの速さを左右するものを書き、矢印でつなぐ。矢印には、同じ向きに動くか（増えれば増える）、逆向きに動くか（増えれば減る）を添える

守ること:

- 目に見えにくいもの（信頼、やる気、知識の偏り）もストックとして扱う。構造の中心にあることが多い
- 境界を決める。どこまでを内側として描くかを書き、外側は前提として扱う

## 3. ループを見つける

やること:

1. 矢印をたどって、元の要素に戻ってくる輪を探す
2. 輪ごとに種類を見分ける
   - 強め合うループ: 一方向に変化を加速させる。好循環にも悪循環にもなる
   - 釣り合わせるループ: 目標や限界に向かって変化を抑える
3. 時系列で見たパターンが、どのループの組み合わせで説明できるかを確かめる。説明できなければ、要素かつながりが足りていない

守ること:

- ループは仮説として扱う。関係者に見せて、実感と合うかを確かめる

## 4. 遅れを見る

やること:

1. 打ち手から効果が出るまでの時間差を、つながりごとに書く
2. 遅れのあるつながりで、効果を待てずに打ち手を重ねていないかを確かめる。重ねると行き過ぎや揺れが起きる
3. 遅れの長い打ち手は、効果が出るまでの間に何を見て判断するかを先に決める

## 5. 効く場所を選ぶ

やること:

1. 手を入れる場所の候補を挙げる。効きやすさは、おおむね次の順に大きくなる
   - 数値を変える（人数、予算、上限値）
   - 流れの速さや遅れを変える
   - ループを足す・切る・弱める
   - 情報の流れを変える（誰が何をいつ知るか）
   - ルールや権限を変える
   - 目的を変える
2. 効きの大きさと、変える難しさを並べて選ぶ
3. 選んだ打ち手が、ほかのループにどう効くかをたどる。副作用が出る場所を先に書く

守ること:

- 数値の変更だけで済ませない。構造が同じなら、問題は戻ってくる
- 打ち手を入れたら、時系列のパターンが変わったかで効果を確かめる

## 6. 点検

描き終えたら、次の型に当てはまるところがないかを見る。

| 型 | 見分け方 | 直し方 |
| :--- | :--- | :--- |
| 対症療法が根本を弱めている | 応急処置で楽になるほど、根本の対策が後回しになり、応急処置への依存が増えている | 応急処置を続けながら、根本の対策に時間を確保する仕組みを入れる |
| 打ち手が裏目に出ている | 打ち手で一度良くなったあと、遅れて副作用が出て悪化している | 遅れて出る影響をたどり、打ち手を変えるか副作用を抑える手を足す |
| 成長が頭打ちになっている | 伸ばす取り組みを強めても、伸びが止まっている | 伸ばす側ではなく、抑えている制約を探して緩める |
| 部分最適が全体を悪くしている | 各チームが自分の指標を上げるほど、全体の成果が下がっている | 共通の目的と、全体を見る指標を置く |
| 共有資源が枯れている | 各自が合理的に使うほど、共有のもの（人、環境、時間）が減っている | 使い方のルールか、使った分が見える仕組みを入れる |
| 遅れを無視している | 効果が出る前に打ち手を重ね、行き過ぎや揺れが起きている | 効果を待つ期間と、その間に見る指標を決める |
| 境界が狭すぎる | 描いた図の外側にある要素で、問題が説明されてしまう | 境界を広げて描き直す。広げられないなら、前提として明記する |
