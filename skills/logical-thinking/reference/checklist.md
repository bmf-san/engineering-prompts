# 筋が通らなくなる型

| 型 | 見分け方 | 直し方 |
| :--- | :--- | :--- |
| 結論がない | 情報は並んでいるが、「だから何か」がどこにも書かれていない | 一番言いたいことを一文で冒頭に置き、情報をその根拠として並べ直す |
| 根拠が主張を支えていない | 話題が同じだけで、根拠が正しくても主張は言えない | 「なぜそう言えるか」に答えている根拠だけを残す |
| 前提が隠れている | 書き手には当たり前で、読み手には共有されていない前提に頼っている | 前提を書き出す。読み手が受け入れない前提なら、それ自体を根拠で支える |
| 軸が混ざっている | 同じ階層に、別の軸で分けた項目が並んでいる（例: 手順と担当者が同じ列にある） | 軸を 1 つに決め、ほかの軸の項目は別の階層か別の表に移す |
| 抽象度がそろっていない | 同じ階層に、大きな話と細かな話が並んでいる | 細かい話を、それを含む大きな項目の下に移す |
| 「その他」が大きい | 分類に収まらない項目が多い | 分ける目的に戻り、軸を選び直す |
| 選択肢を絞りすぎている | 二択で話しているが、ほかの選択肢を検討していない | ほかの選択肢を書き出し、落とした理由を添える |
| 1 つの例から一般化している | 型や原則の裏付けが、1 つの事例だけ | 別の事例に当てはめて確かめる。足りなければ、その事例での話にとどめる |
| 抽象語だけで具体がない | 「品質を高める」「連携を強化する」で止まっている | 誰が、何を、どの状態にするかを書く。具体例を 1 つ添える |
| 伝わらない言葉を使っている | 書き手が作った言い回しや略語が、定義されずに使われている | 読み手が普段使う言葉に言い換える。言い換えられなければ定義を書く |
| 因果と順序を取り違えている | 先に起きたこと、同時に起きたことを原因として書いている | 原因と言えるだけの根拠を足すか、「同じ時期に起きた」と書くにとどめる |
