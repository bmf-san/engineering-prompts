# 点検の観点

## 人を傷つける

| 観点 | 見分け方 | 直し方 |
| :--- | :--- | :--- |
| 属性への決めつけ | 性別、年齢、国籍、出身、障害、病気、容姿、学歴、職業、家族構成などで、人をひとまとめに語っている（例: 「若手は〜しない」） | 属性ではなく、観測した行動や個別の事例として書く |
| 見下し | 「こんなことも知らない」「簡単」「誰でも分かる」など、分からない人を下に置く言い方がある | 難しさの評価を外す。知らない人に向けた説明に変える |
| 比較で下げる | 何かを持ち上げるために、特定の人・組織・技術・前職を下げている | 比較を外し、良いと思う理由だけを書く |
| 失敗の晒し | 他人の失敗や過去の発言を、本人の了承なく題材にしている | 個人が分からない形にするか、自分の失敗として書く |
| 当事者不在の話 | その場にいない人や組織について、反論できない形で語っている | 事実に絞るか、本人に確認してから書く |
| 苦しみの軽視 | 病気、災害、事件、人の死、ハラスメントを、たとえや冗談に使っている | たとえを別のものに変える。題材にしない |

## 誤解・切り取り

| 観点 | 見分け方 | 直し方 |
| :--- | :--- | :--- |
| 主語が大きい | 「エンジニアは」「日本の会社は」など、広い集団について言い切っている | 主語を、自分や観測した範囲に小さくする |
| 断定・極論 | 「絶対」「ありえない」「〜は終わり」など、反例一つで崩れる言い方 | 条件と範囲を添える。「〜の場合は」 |
| 内輪の冗談・皮肉 | 文脈を知っている人にしか冗談と分からない | 削る。残すなら、文脈を本文に書く |
| 切り取られると意味が変わる | 前後の文がないと、逆の意味や攻撃的な意味に読める一文がある | その一文だけで意図が伝わるように書き直す |
| 事実と意見が混ざる | 推測や印象を、事実のように書いている | 事実と意見を分け、意見は意見として書く |
| 未確認の情報 | 伝聞や未確認の数字を、確かめずに広げている | 一次情報に当たる。当たれないなら出さない |

## 第三者・所属先への影響

| 観点 | 見分け方 | 直し方 |
| :--- | :--- | :--- |
| 個人の情報 | 名前、顔、所属、居場所、予定、やりとりの画面など、個人が特定できる情報がある | 外すか、本人の了承を取る |
| 組織の見解と読まれる | 所属が見える場で、組織の方針や評価のように読める書き方をしている | 個人の意見であることを明確にする。組織の判断に関わることは書かない |
| 取引先・競合への言及 | 社外の組織を名指しで評価している | 名指しを外すか、事実の記述にとどめる |
| 非公開情報 | 公開されていない数字、計画、社内の議論、障害の詳細が入っている | 公開済みの情報か、出してよいと許可を得た情報だけにする |
| 権利 | 他人の文章・画像・図・コードを、引用の範囲を超えて載せている | 引用の形（出典、必要最小限、主従）にするか、自分で作り直す |

## 時と場所

| 観点 | 見分け方 | 直し方 |
| :--- | :--- | :--- |
| タイミング | 災害、事件、訃報、障害の直後に、関係する話題を軽く扱っている | 時期をずらすか、出さない |
| 便乗 | 他人の炎上や議論に乗って、注目を集めようとしている | 言いたいことがあるなら、元の議論から切り離して書く |
| 場違い | その場の目的と関係のない主張や、私的な感情を出している | 場を変える。個別に伝える |
| 感情のまま書いている | 怒りや苛立ちのまま書き、すぐ出そうとしている | 時間を置いて読み直す |
