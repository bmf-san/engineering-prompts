# 社会性フィルター

発言や文章を出す前に、届きうる読み手の立場で読み直し、不用意に人を傷つけるところ、誤解や切り取りで燃えるところ、第三者に迷惑をかけるところを見つける。言いたいことは残したまま、伝わり方を直す。

## いつ使うか

- SNS の投稿、ブログ記事、登壇資料、公開リポジトリの文章を出す前
- 社内の広いチャンネルへの投稿、PR やレビューのコメント、Issue への返信を送る前
- 批判・反論・感情が入った文章を書いたとき
- 公開した発言に反応がつき、返信・訂正・謝罪を書くとき

文章の分かりやすさは `technical-writing`、事実として正しいかは `fact-verification` を使う。登壇資料に非公開情報が入っていないかは `talk-preparation` の [非公開情報の確認](../talk-preparation/reference/disclosure.md) を使う。

## 1. 届き方を確かめる

やること:

1. どこに出すかと、そこで読む人を書く
2. 想定外に届く読み手を書く。転載、スクリーンショット、検索、引用での拡散を前提にする
   - 名前や所属が出ている人と、その周りの人
   - 話題にした属性や立場に当てはまる人
   - 前提や文脈を知らない人
   - 反対の立場の人
3. 一文だけ切り取られて読まれたときの意味を確かめる
4. 自分がどの立場で書いているかを確かめる。所属や役職が見える場では、組織の見解として読まれうる
5. 残り方を確かめる。消せるか、消しても写しが残るか

守ること:

- 「この場の読み手なら分かる」を前提にしない。届く範囲は書き手が決められない

## 2. 点検する

[reference/checklist.md](reference/checklist.md) の観点で、文章を一文ずつ読む。見つけたものは次の形で書く。

| 項目 | 書くこと |
| :--- | :--- |
| 箇所 | 該当する文の引用 |
| 読み手 | 誰が読んだときに問題になるか |
| 起こりうること | その読み手がどう受け取り、何が起きうるか |
| 深刻度 | 高・中・低。起きやすさと、起きたときの影響の大きさで決める |
| 直し方 | 言いたいことを残した言い換えの案 |

守ること:

- 言葉の機械的な置き換えで済ませない。誰がどう受け取るかで判断する
- 書き手の意図ではなく、読み手が受け取りうる意味で判断する

## 3. 出すかどうかを決める

やること:

1. 深刻度が高いものがあれば、直すか、出さない
2. 直したら、もう一度 1 と 2 を通す
3. 迷いが残るなら、時間を置いて読み直すか、立場の違う人に読んでもらう
4. 出さないと決めたら、その場で伝えるべきことが別の手段（個別の連絡、場を変える）で伝えられないかを考える

守ること:

- 出すかどうかを決めるのは書き手。このスキルはリスクと直し方を示すところまで
- 正当な批判や問題提起を消すことを目的にしない。伝え方を直して、言うべきことは言う

## 4. 直す

やること:

1. 主語を小さくする。「みんな」「普通は」を、自分や観測した範囲に置き換える
2. 意見は自分の意見として書く（「〜だと思う」「私の場合は」）。事実と分ける
3. 批判は人ではなく、行為や判断に向ける
4. 条件や範囲を添える（「この規模なら」「今回のケースでは」）
5. 名前や特定につながる情報を外す。外せないなら、本人の了承を取る
6. 内輪の冗談・皮肉・煽りは削る。残すなら、文脈を知らない人にも冗談と分かる形にする

守ること:

- 角を取りすぎて、言いたいことを消さない。直したあとに一番言いたいことが残っているかを確かめる
- 謝罪や前置きを重ねて、本文を埋もれさせない

## 5. 出したあと

やること:

1. 誤りを指摘されたら、確かめてから訂正する。訂正は元の発言と同じ場所・同じ届き方で出す
2. 消すときは、消した理由を添える。黙って消すと、消したこと自体が憶測を呼ぶ
3. 謝罪するときは、何について、誰に対して謝るのかを具体的に書く。言い訳や「不快に思った方がいたら」のような条件付けを足さない
4. 議論が広がったら、返信を重ねる前に 1 から通す。感情が動いているときは、時間を置く

守ること:

- 反応の数で判断しない。少数でも、傷ついた人がいる指摘は受け止める
- 反応した人を個別に言い負かしにいかない
