# メンバーの評価

評価者として、メンバーの目標の達成度と行動を、期初の達成基準と確かめた事実で評価し、本人へのフィードバックになる形で書く。

## いつ使うか

- 中間・期末に、評価者としてメンバーの評価を付けるとき
- 評価会議（キャリブレーション）の資料を作るとき
- 本人の自己評価と自分の評価にギャップがあり、根拠を整えたいとき

自分の評価は `self-evaluation`、昇格の推薦は `promotion-assessment` を使う。

## 入力

- 評価制度のガイド。評価の段階、点数、目標の区分と重み、総合の出し方、目標外の貢献の扱い
- 本人の期初の目標と達成基準。評価シートの写しではなく、元の目標のページ
- 等級要件
- 本人の活動。PR、文書、チャットの発言、日々の記録
- 組織の下書きフォーマット。あればそれに従い、この skill の手順は中身の決め方と書き方に使う

## 1. 独自に調べる

やること:

1. 本人の自己評価と実績欄を見る前に、本人の活動を集める
2. 集めた活動を、目標ごとに事実として書く。評価はまだ付けない
3. 行動評価の仮の評価を、この段階で付ける

守ること:

- 本人の主張を先に読まない。主張に引っ張られて、観測していない成果を数えやすくなる
- 成果物の作成者を確かめる。評価者や他のメンバーが書いたものを、本人の成果に数えない
- 対象期間の外の成果と行動は、次の評価に回す

## 2. 本人の記載を確かめる

やること:

1. 本人の目標と達成基準、実績欄の記載を写す
2. 実績欄の主張と、そこで挙げられた証跡を、開けるものはすべて開いて確かめる
3. 独自調査になかった実績は、事実を確かめてから評価に使う
4. 確かめられないものは、評価のヒアリングで本人に聞く

守ること:

- 主張の出どころを確かめただけで止めない。中身まで開く
- 議論や相談の事例は、その後どうなったか（相手がその方針で進めたか）まで追う

## 3. 判定する

やること:

1. 目標ごとに、達成基準の水準ごとの到達を書く。中間なら、期末の基準ごとに現在の到達と期末の着地見込みを書く
2. 評価を一つ選ぶ。中間の評価は、現在の到達ではなく期末の着地見込みで付ける
3. 目標外の貢献は、目標の評価を決めたあとに、引き上げるかを別に判断する（制度に引き上げの決まりがある場合）
4. 総合を、評価制度のガイドの出し方で出す
5. 行動評価を見直す

守ること:

- 期初の達成基準に照らす。定義が空欄の水準をどう扱ったかも書く
- チーム全員で共有する目標は、全員に同じ評価を付ける。判定は上位の評価者とそろえる
- 役割の目標は、チームの目標の到達度に引きずらせない。本人の役割・判断・巻き込み・成果物の質で見る
- 達成基準の水準が、本人の等級より上の等級の期待に寄っていないかを見る。寄っているなら等級の期待に照らして判定し、目標の調整として本人に伝える
- 姿勢や進め方は、目標の達成度ではなく行動評価で扱う
- 目標外の貢献の中身を、目標の根拠に混ぜない
- 総合は、加重平均で決める制度なら基準点以上となる評価にする。最も近い評価にしない

## 4. 根拠を書く

やること:

1. 根拠は本人へのフィードバックとして書く。期待を上回った点、届かなかった点、次に期待すること
2. 評価シートに転記する欄と、判定の材料（判定メモ）を分ける
3. 確定の前に、組織の確認項目を通す

守ること:

- 事実だけを書く。推測や意図を書くときは、それと分かる書き方にする
- 数値は、対象・期間・母数を本文に書く。因果を言い過ぎず、時系列で書く
- 転記する欄は、そのまま貼れる文にする。PR・Issue の番号、URL、ID、確認のメモは判定メモに置く
- 「次に期待すること」に具体例を並べない。本人の行動の幅を狭める
- 行動評価には「次に期待すること」を添えない。事例は、目標の実績と重ねない

## 5. 自己評価と見比べる

やること:

1. 確定して本人の自己評価が見られるようになったら、欄ごとに見比べる
2. ギャップのある欄に、判断の根拠を足す
3. 必要なら面談する

守ること:

- ギャップを埋めるために評価を動かすのは、新しい事実が出たときだけにする

## 6. キャリブレーションに備える

評価会議で他の評価者と水準をそろえる前に、判断の分かれそうな箇所を資料にまとめる。構成と書き方は [reference/calibration.md](reference/calibration.md) を参照。

## 守ること

- 判定は評価者がする。この skill は材料と案までを作る
- 独自調査、判定メモ、キャリブレーションの資料は、評価者だけが見る場所に置く。本人に伝える内容と範囲は、組織の決まりに従う
- 限定して共有された情報（非公開の報告など）を材料にするかは、扱いを決めてから使う
